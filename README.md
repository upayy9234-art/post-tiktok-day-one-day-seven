**Pocket Grove** is a tiny top-down village game, built by an AI agent: one grass map with a river
down its right edge, a dirt loop path, and a hero who walks it. On day one the village is a single
hut, two trees and a bare dirt patch. After a week of daily updates the same map — same spawn,
same camera — holds eight buildings, a well, market stalls, fences, a planted crop field,
lanterns, neighbours on the paths, a cart and birds overhead.

The entry is a 20-second vertical TikTok video of that week. It holds one still camera on the
game: the hero sets out across the day-one map, the picture cuts on identical framing to day
seven with the village bustling around the same walk, and it closes on the newer build —
"Built by my AI agent in 7 days · Start yours at make.fun" — before make.fun's referral end
card. `game.html` is the playable game (open it in a browser; the button switches day one and
day seven), and `make_video.py` is the Python-stdlib renderer that drew every frame of the
video from the same layout data. `VIDEO.json` names the posted video; `main.ts` hands it in.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
